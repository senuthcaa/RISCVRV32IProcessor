- R-Type: Register to register instructions.
- I-Type: Register to immediate instructions.
- S-Type: Stores info from a register into a memory address.
- B-Type: Branching if a condition is true.
- U-Type: "Loading big numbers by putting a 20-bit constant in the top of a register: lui, auipc" don't fully understand yet.
- J-Type: Jumping but remember which line you came from.
